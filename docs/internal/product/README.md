# Product requirements (PRDs)

Store **product** artifacts here: problems, goals, scope, success metrics, and release notes—separate from **ADRs** (technical decisions) and **support** articles (end-user wording).

## Index

| Document | Status | Summary |
| --- | --- | --- |
| *(none yet)* | — | Add PRDs as `YYYY-MM-slug.md` or `NNN-title.md` |

## Naming

- Prefer **`YYYY-MM-short-title.md`** or **`prd-NNN-short-title.md`** for sortability.
- One PRD can span multiple engineering PRs; link GitHub issues/PRs in the doc.
